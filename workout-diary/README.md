# Workout Diary

## Описание
Workout Diary — это веб-приложение-календарь для планирования и отслеживания тренировок. Для доступа к календарю пользователи должны войти в свой профиль с помощью логина и пароля. Приложение позволяет отмечать дни тренировок, выбирать тип тренировки (на всё тело, верхнюю часть тела или нижнюю часть тела), добавлять новые упражнения в базу, а также записывать существующие упражнения в тренировочный день с указанием количества подходов, повторений и веса. Данные сохраняются в Firebase. Проект построен на Vite с использованием React и хостится на Vercel.

## Функционал
- Вход в профиль с использованием логина и пароля для доступа к календарю
- Календарь для отметки дней тренировок
- Выбор типа тренировки: на всё тело, верхнюю часть тела или нижнюю часть тела
- Добавление новых упражнений в базу
- Добавление существующих упражнений в тренировочный день с указанием количества подходов, повторений и веса
- Сохранение данных о тренировках в Firebase

## Технологии
- **Frontend**: Vite, React, React Calendar
- **Стили**: React Bootstrap, Bootstrap
- **Backend**: Firebase (Firestore для хранения данных, Authentication для входа в профиль)
- **Хостинг**: Vercel
- **Линтер**: ESLint с плагинами `eslint-plugin-react-hooks` и `eslint-plugin-react-refresh`
- **Дополнительно**: Vite Plugin SVGR (для работы с SVG как React-компонентами)

## Использование
Готовым приложением можно пользоваться по ссылке: [https://workout-diary-dbap.vercel.app](https://workout-diary-dbap.vercel.app).

1. Перейдите по ссылке [https://workout-diary-dbap.vercel.app](https://workout-diary-dbap.vercel.app).
2. Войдите в свой профиль или создайте новый профиль, используя логин и пароль.
3. Отмечайте дни тренировок, выбирайте тип тренировки (всё тело, верх, низ), добавляйте новые или существующие упражнения с указанием подходов, повторений и веса.
